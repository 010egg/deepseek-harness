# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

Web 设置中的只读**插件列表**标签页。浏览器插件注册一个 id 为 `all` 的本地化 `settings.plugins.tab` 贡献；“插件”分区拥有导航入口与标签栏。插件激活期间不会读取 Remote；首次选择该标签页时才挂载组件，并通过 [`api-remotes`](../../api/remotes/README.zh.md) 懒调用 `ctx.remote.pluginInventory.list()`。

该标签页以可折叠的分类文件夹展示可搜索的清单：Agent 与模型、工具与自动化、执行与权限、会话与数据、Web 服务、浏览器界面、系统基础与其他插件。分类属于客户端自有的展示元数据：精确目录把内置模块标识映射到分类，任何自定义或未知模块都会落入**其他插件**，因此仓库外的部署无需遵循命名约定也能正常展示。文件夹顺序固定，文件夹内条目保持 Loader 顺序。每个文件夹行显示开合状态的文件夹图标、分类名与条目数量，点击即可切换为单列的紧凑文件行列表，折叠状态下占用极小。输入搜索词会自动展开所有有匹配的文件夹。每个文件行显示插件图标、模块短名称与小的有效启停标签；已启用的条目还会以彩色圆点表示根 fiber 状态。展开某一行后会直接展示 Loader 树条目 id，不附加重复的字段标题，并列出有效配置状态；已启用的条目还会列出 Cordis 状态，已停用的条目则省略重复的“未挂载”运行状态。条目 id 仍作为 React key、展开标识、详情值与额外的搜索目标；代码不按字符串形状对它分类。加载、空结果、无匹配结果与通用失败状态只属于已挂载组件；读取失败后可以重试，且不会暴露传输细节。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 模型体验

无，因为本包只在浏览器设置中展示 Host 拥有的部署快照，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **每次 Settings 挂载或重试只读取一份快照** —— 标签页不订阅 Loader 变化，也不会在重连后自动重新读取；切换标签页会保留当前快照，重新打开 Settings 则会取得新快照。
- **只读 Loader 视图** —— 本地搜索不会额外引入来源、当前浏览器激活诊断、按来源分组或插件修改控件；分类目录属于客户端自有，不随 Host 快照传输。
